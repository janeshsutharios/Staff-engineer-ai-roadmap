# Month 04 — LLM APIs & Structured Output

**Status:** Not started

## Outcome

Ship a useful AI feature through a backend service.

## Starting point

Complete month 3: a tested backend. No machine-learning background is assumed.

## Weekly sequence

| Week | Work in this order |
|---|---|
| 1 | Learn AI versus machine learning versus deep learning versus large language models (LLMs). Understand training versus inference and what a model predicts. |
| 2 | Learn vectors, dot products, cosine similarity and basic probability intuition with tiny Python examples. Study tokenization, embeddings and an intuitive attention/transformer diagram. |
| 3 | Call one hosted model through your backend. Learn prompts, context limits and structured output; validate results and keep credentials server-side. |
| 4 | Build the AI Notes feature. Create 20 representative input examples and a scoring rubric; record quality, latency and estimated cost as a baseline. |

## Ready to move on when

Explain the request-to-model flow, demonstrate structured outputs, and show cases where the feature fails. If this is not yet comfortable, extend this month before continuing.

## Optional / defer

Training a transformer, calculus-heavy derivations and multiple provider frameworks. Streaming is optional after a working request/response flow.

## Topic reference

- Tokens, context windows, prompts and model selection.
- Structured outputs, streaming and introductory tool calling.
- Latency, cost, timeouts and response validation.

## Build

Prototype AI Notes: SwiftUI → FastAPI → model API, with summaries and extracted action items. Record it as an AI integration case study.

## Completion checklist

- [ ] Validate structured action items against a schema.
- [ ] Keep provider credentials on the backend.
- [ ] Evaluate 20 representative examples with a rubric; record quality, latency and estimated cost.
