# Month 01 — Python, Git & APIs

**Status:** Not started

## Outcome

Become comfortable building Python services using existing iOS engineering experience.

## Starting point

No backend or AI knowledge required. Use your Swift experience to compare language concepts.

## Weekly sequence

| Week | Work in this order |
|---|---|
| 1 | Learn Python syntax, collections, functions, modules and exceptions. Write a command-line expense calculator. |
| 2 | Add classes, type hints, a virtual environment and simple tests. Compare these with familiar Swift patterns. |
| 3 | Learn client/server basics, HTTP methods, status codes and JSON. Call a sample API from Python. |
| 4 | Use a minimal FastAPI route to return expenses from memory. Call it from an iOS client; persistence comes next month. |

## Ready to move on when

Explain a request and response, run your Python code independently, and debug a basic API error. If this is not yet comfortable, extend this month before continuing.

## Optional / defer

Advanced async patterns and packaging internals.

## Topic reference

- Python syntax, classes, type hints, virtual environments and package management.
- Async/await, HTTP, JSON and REST conventions.
- Git branches, commits and code review.

## Build

Build a small REST API that returns JSON and can be called from an iOS client.

## Completion checklist

- [ ] Implement and document a small resource endpoint.
- [ ] Demonstrate valid requests and useful error responses.
- [ ] Record Python versus Swift differences in notes/python.md.
