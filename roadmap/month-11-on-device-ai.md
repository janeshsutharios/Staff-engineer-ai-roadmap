# Month 11 — On-device AI & iOS

**Status:** Not started

## Outcome

Combine mobile expertise with local and cloud AI.

## Starting point

Complete month 10: a reliable cloud AI feature and evaluation approach; apply your existing iOS expertise.

## Weekly sequence

| Week | Work in this order |
|---|---|
| 1 | Choose one local AI feature. Check device/OS availability and model requirements in current Apple documentation. |
| 2 | Implement it with one appropriate Apple framework and test offline behavior. Study Core ML and Foundation Models roles without requiring both. |
| 3 | Design explicit local/cloud routing and user-visible data handling. Test unavailable-model and unsupported-device paths. |
| 4 | Measure quality, latency and memory on named devices. Reuse your evaluation cases and record the privacy/performance trade-offs. |

## Ready to move on when

Demonstrate a local feature and predictable fallback, with measured device constraints. If this is not yet comfortable, extend this month before continuing.

## Optional / defer

MLX experiments, model conversion and custom quantization.

## Topic reference

- Core ML, Foundation Models and MLX concepts.
- On-device inference, quantization and memory constraints.
- Privacy, offline behavior and local/cloud routing.

## Build

Prototype a personal assistant with a local AI capability and an explicit cloud fallback; document it alongside the AI Agent.

## Completion checklist

- [ ] Check framework, OS and device requirements before implementation.
- [ ] Demonstrate offline and unsupported-device behavior.
- [ ] Compare latency, memory use and data leaving the device.
