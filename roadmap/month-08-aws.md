# Month 08 — AWS, Deployment & CI/CD

**Status:** Not started

## Outcome

Deploy and operate one complete system.

## Starting point

Complete month 7: a containerized application with background work and automated checks.

## Weekly sequence

| Week | Work in this order |
|---|---|
| 1 | Learn cloud basics, regions, networking, IAM permissions, secrets and spending budgets. Select one small deployment approach. |
| 2 | Deploy the API, database and required worker. Understand S3 for files; add only the services your project uses. |
| 3 | Extend CI into continuous delivery (CD). Run tests and small AI regression checks before release; practice rollback. |
| 4 | Add request IDs, logs and alerts, and trace model/tool calls. Record tokens, latency, failures and cost per successful task. Practice database restore and teardown. |

## Ready to move on when

Deploy from documented steps, identify a failed AI request, restore data and roll back a release. If this is not yet comfortable, extend this month before continuing.

## Optional / defer

Multiple AWS compute services, Kubernetes, high availability and elaborate load balancing.

## Topic reference

- IAM, Secrets Manager, CloudWatch and budget controls.
- EC2/container deployment, S3, RDS and load balancing.
- Lambda use cases, CI/CD, backups and rollback.

## Build

Deploy one existing project on AWS using the smallest architecture that meets its requirements.

## Completion checklist

- [ ] Automate validation and deployment with CI/CD, including small AI regression checks.
- [ ] Configure secrets, logs, alerts and a spending budget; trace model/tool calls and measure cost per successful task.
- [ ] Demonstrate rollback and database restore; document teardown.

## Career & income objective

Offer deployment and operational support once delivery is repeatable.

## Portfolio & Staff-level evidence

Publish a deployment diagram, cost estimate and recovery runbook.
