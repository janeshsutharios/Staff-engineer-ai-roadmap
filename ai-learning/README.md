# AI engineering learning journal

Started: 28 October 2026 (Asia/Kolkata)

This folder holds lesson guides, your own notes, practice code and evidence of progress.
A prepared lesson is not proof of completion. Mark a topic learned only after you can
explain it and repeat the exercise independently.

## Start here

1. Open this `ai-learning` folder in VS Code: File → Open Folder.
2. Read `month-01-python/day-01.md`.
3. Run and edit `month-01-python/practice/day_01.py`.
4. Fill in `month-01-python/notes/2026-10-28.md` after practising.
5. Update `progress.md` with what you actually completed.

## Folder guide

- `progress.md`: overview and evidence of completion.
- `month-01-python/day-01.md`: today's lesson and exercises.
- `month-01-python/notes/`: dated learning records and Python versus Swift notes.
- `month-01-python/practice/`: code you write and run.
- `templates/session.md`: copy for each future learning session.

Use dated notes such as `2026-10-29.md`. Keep failed attempts and the explanation of
what fixed them; these are useful learning evidence. These files are versioned in this repository.

## Learning routine

Spend about 10 minutes reading, 30 minutes coding, 10 minutes debugging and
10 minutes recording what you learned. Before running a small example, predict its
output. Change one thing, run again, and explain the difference. Ask for hints before
full solutions; retype the final version without looking.
