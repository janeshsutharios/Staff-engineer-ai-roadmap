## Learning order and optional courses

Use the monthly weekly sequence to select relevant lessons; do not study every resource at once.

| Stage | What to use | Readiness requirement |
|---|---|---|
| Months 1–3 | Python tutorial, FastAPI tutorial, PostgreSQL basics and Docker documentation | Start with existing programming experience; no AI required |
| Month 4 | AI vocabulary and small vector/probability exercises, then one provider API | A working Python backend |
| Months 4–6 | [InterviewReady AI Engineering](https://interviewready.io/course-page/ai-engineering): optional support for vectors, LLM internals and agent concepts | Study fundamentals before advanced optimization sections |
| Months 6–10 | [AIEngg cohort](https://aiengg.dev/): optional structured practice in production AI | First build a basic RAG or agent application; the published cohort explicitly assumes that background |
| Months 8–12 | Cloud, observability and platform documentation for the system actually built | Complete earlier readiness checks before expanding infrastructure |

Course placement is based on the public syllabi reviewed on 2026-10-28, not an independent assessment of teaching quality. Neither purchase nor certification is required for this roadmap. Recheck syllabus, prerequisites, support and terms before enrolling.
